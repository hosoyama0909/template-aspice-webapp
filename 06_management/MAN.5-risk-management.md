# MAN.5 リスク管理

プロジェクト・プロダクトのリスクを洗い出し、対応を決めて追跡する。
発生確率×影響で優先度を付け、対応（回避／低減／受容）を記録する。

| ID | リスク | 分類 | 確率 | 影響 | 優先度 | 対応 |
|----|--------|------|------|------|--------|------|
| RSK-01 | （例）localStorage 破損でデータ消失 | データ | 低 | 大 | 中 | 書出/取込機能を用意（低減） |
| RSK-02 | （例）個人データの外部送信 | プライバシー | 低 | 大 | 高 | 送信データをレビューで検査（回避） |
| RSK-03 | | | | | | |

## 見直し
- 新機能の影響分析（CRテンプレ）で新規リスクが出たら、ここへ追記する。
