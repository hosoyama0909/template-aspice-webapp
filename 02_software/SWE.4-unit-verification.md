# SWE.4 ソフトウェア単体検証

DOM に依存しない純関数（計算・整形・変換）の単体テスト仕様。
テスト実体は `04_test/unit/` に置く。各 UTC は対応する SWD / SWR に紐づける。

| UTC | 対象関数(SWD) | 入力 | 期待出力 | 対応SWR |
|-----|---------------|------|----------|---------|
| UTC-XXX-01 | （例）`ageStr(dob)` | 生年月日 | "5歳2ヶ月" | SWR-XXX-02 |
| UTC-XXX-02 | | | | |

## 方針
- 境界値（空・0・最大・不正入力）を必ず1ケース入れる。
- 純関数として切り出せない箇所は、適格性テスト（SWE.6）側でカバーする。
