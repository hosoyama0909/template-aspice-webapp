# SWE.1 ソフトウェア要求

システム要求（SYR）を、ソフトウェアとして実装する単位（SWR）に分解する。
各 SWR は由来 SYR に紐づける。機能ごとに中間キー（`SWR-<機能>-NN`）を付ける。

| ID | ソフトウェア要求 | 由来SYR | 受け入れ基準 |
|----|------------------|---------|--------------|
| SWR-XXX-01 | （例）記録ボタン押下で1件を localStorage に保存する | SYR-01 | 保存後リロードしても残る |
| SWR-XXX-02 | | | |
| SWR-DATA-01 | すべての状態は `persist()` 経由で localStorage に保存する | SYR-N2 | |

> 「受け入れ基準」は後で QTC / UTC のもとになる。曖昧語を避け、観測可能な条件で書く。
