# SYS.2 システム要求

ステークホルダ要求（STK）を、検証可能な「システムが満たすべき条件」に分解する。
各 SYR は、由来する STK と対応づける（上流トレース）。非機能要求は `SYR-N*` で採番する。

## 機能要求

| ID | システム要求 | 由来STK | 検証方法 |
|----|--------------|---------|----------|
| SYR-01 | （例）ユーザは1タップで〇〇を記録できる | STK-01 | 適格性テスト |
| SYR-02 | | | |

## 非機能要求

| ID | 非機能要求 | 由来STK | 検証方法 |
|----|-----------|---------|----------|
| SYR-N1 | ログイン不要・オフラインで動作する | STK- | 手動 |
| SYR-N2 | 個人データは端末内（localStorage）にのみ保存する | STK- | コードレビュー |
| SYR-N3 | | | |

> 「〜が速い/使いやすい」等は測れる形（時間・回数・条件）に落とす。
