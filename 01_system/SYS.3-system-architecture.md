# SYS.3 システムアーキテクチャ

システムを構成要素に分け、SYR をどの要素が満たすか（配置）を示す。
単一ファイル webapp の場合、システム＝「ブラウザ上で動く単一HTML＋localStorage」が基本形。

## 構成要素

```
[ブラウザ]
  └─ index.html（単一ファイル）
       ├─ UI 層（画面・入力）
       ├─ ロジック層（純関数・状態管理）
       └─ 永続化層（localStorage ラッパ）
  （必要なら）外部サービス：… ※個人データは送らない
```

## 要素とシステム要求の対応

| 構成要素 | 担当するSYR | 備考 |
|----------|-------------|------|
| UI 層 | SYR-01, ... | |
| 永続化層 | SYR-N2 | localStorage のみ |
| （外部） | | 使う場合のみ。送信データを明記 |

## 設計判断（なぜこの構成か）
- （例）サーバレス単一ファイル：ログイン不要・無料公開・オフライン動作のため。
