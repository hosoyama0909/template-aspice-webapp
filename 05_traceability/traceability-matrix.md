# トレーサビリティ・マトリクス

A-SPICE の中核。**上流（なぜ）から下流（実装・テスト）まで双方向にたどれる**ことを保証する。
新機能を追加するたびに、この表へ1行足す（要求→設計→実装→テストが1本につながる）。

## 1. 縦のトレース（STK → テスト）

| STK | SYR | SWR | SWA(コンポーネント) | SWD(設計) | 実装(index.html) | テスト |
|-----|-----|-----|--------------------|-----------|------------------|--------|
| STK-01 | SYR-01 | SWR-XXX-01 | SWA-XXX | SWD-xxx | `addItem()` | QTC-XXX-01 |
| | | | | | | |

## 2. 横断（データ・非機能）

| SYR | SWR | 実装 | テスト |
|-----|-----|------|--------|
| SYR-N2 | SWR-DATA-01 | `persist()` / localStorage | ITC-01 |
| 回帰 | SWR-CORE-01 | 既存 render 関数 | QTC-REG-01 |

## 使い方
- 1行 = 1つの追跡可能な要求。抜けがある（例：SWRはあるがテストが空）と一貫性が崩れる。
- レビュー時に、この表の各行が実際のコード・テストと一致しているか確認する。
